# nikhil-portfolio
A responsive personal portfolio website developed using HTML5, CSS3, and JavaScript as part of my Fundamentals of Web Technology (FWT) project. The website demonstrates basic and advanced web-development concepts including HTML document structure, semantic HTML elements, headings, paragraphs, lists, links, images, forms, divs, classes, IDs, CSS selectors, colors, gradients, borders, border-radius, padding, margins, the CSS box model, Flexbox, CSS Grid, responsive design using media queries, pseudo-classes, hover effects, transitions, transforms, shadows, CSS variables, and basic JavaScript interactivity. The portfolio contains sections for my introduction, education, skills, projects, hobbies, interests, goals, and contact information, along with navigation buttons and external links. This project helped me understand how HTML creates the structure, CSS controls the design and layout, and JavaScript adds functionality and interactivity to a modern webpage.
